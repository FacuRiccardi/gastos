Privacy policy

card-expenses · Last updated: November 2, 2026

What this app is

card-expenses is a personal, single-user tool. It is used only by its owner, with the owner's own Google account, to keep track of credit card purchases.

What data it accesses

With the owner's permission it has read-only access to Gmail (the gmail.readonly scope). It only looks at emails that carry a specific label, which a Gmail filter applies to purchase notifications sent by the owner's bank. It does not read, search or use any other email.

What data it stores

From each purchase notification it extracts and stores: the purchase date, the merchant name, the amount and currency, and the last four digits of the card. This data is kept in a private database that only the owner can access. The content of the emails themselves is not stored.

Sharing

The data is not sold, shared, transferred or disclosed to anyone, and it is not used for advertising or to train any machine learning model. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data is kept for as long as the owner wants it. The owner can delete it at any time from the database, and can revoke the app's access to Gmail at any time at myaccount.google.com/permissions.
